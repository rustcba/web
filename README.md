# AdminPro HTML 后台管理系统

一个纯前端、零依赖的后台管理系统示例。

## 技术栈

- HTML5
- CSS3
- JavaScript
- Canvas

## 功能

- 响应式后台布局
- 侧边栏导航
- 数据统计卡片
- 收入趋势图
- 最近动态
- 订单列表
- 订单状态过滤
- 全局搜索
- 深色 / 浅色主题切换
- CSV 报表导出
- 移动端侧边栏
- 分页交互示例

## 运行

直接打开 `index.html` 即可。

也可以使用任意静态服务器，例如：

```bash
python3 -m http.server 8080
```

然后访问：

http://localhost:8080
